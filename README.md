# ArduinoCore-megaavr (Debug enabled)
This branch contains the Arduino IDE Boards Manager installation
support files for the debug-enabled ArduinoCore-megaavr package. For more
infomation see https://github.com/felias-fogg/ArduinoCore-megaavr and
https://pyavrocd.io

**Deprecated:** debugging the Arduino megaAVR boards is now provided by
megaAvrDebugger, part of the AvrDebugger package
(https://github.com/felias-fogg/AvrDebugger), which works together with the
official Arduino megaAVR Boards.
